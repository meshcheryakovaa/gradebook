# синхронизация при отстающем списке файлов

Скачайте **Gradebook-v14.3.html** из Assets и откройте в браузере. Формат журнала тот же, что в 14.2.

Что исправлено:

- Ошибка «Не все зависимости загружены» больше не отменяет обмен целиком. Она возникала, когда список файлов на Диске ещё не показывал недавно загруженный пакет, а следующий за ним уже был виден — например, у нового участника, который скачивает большой журнал, пока коллега продолжает работать. Теперь приложение перечитывает список, объединяет всё, что уже получено полностью, и дозагружает остальное при следующем обмене. В строке состояния видно, сколько изменений ещё ждут.
- Если за время чтения списка на Диске появились новые файлы, список читается заново, чтобы ни один пакет не был пропущен.

**Обновление:** закройте вкладки с прежней версией, откройте v14.3, войдите в тот же аккаунт и журнал и синхронизируйтесь. Обновите версию у всех участников.
