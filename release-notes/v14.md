# Аккаунты и совместная работа через один Яндекс Диск

- Собственные логины и пароли преподавателей; один общий OAuth-токен Яндекс Диска.
- Личные журналы и общие журналы по имени; раздельные локальные базы аккаунтов.
- Объединение параллельных правок по полям вместо замены всей базы по времени.
- Сохранение обоих вариантов спорной оценки и явный выбор нужного значения.
- Учёт удалений, причинных зависимостей и правок связанных записей.
- Неизменяемые пакеты, устойчивая очередь отправки, проверка содержимого после
  загрузки и повтор после обрыва связи без дублирования операций.
- Автоотправка, проверка входящих правок раз в минуту, состояние обмена и ошибки.
- Экспорт с историей операций; объединение резервной копии того же журнала.

**Скачать `Gradebook-v14.html` ниже**, открыть в браузере. Установка не требуется.
При ограничениях браузерных API используйте локальный HTTP-сервер.

**Переход с v13:** экспортируйте старую базу в JSON, в v14 подключите токен,
создайте аккаунт, откройте журнал и импортируйте JSON один раз на одном устройстве.
Остальные пользователи выбирают то же имя общего журнала и синхронизируются.
Старые облачные файлы v13 сохраняются отдельно и не перезаписываются версией 14.

**Доступ:** владельцы общего токена имеют доступ ко всем файлам папки приложения.
Пароль проверяет вход в интерфейс, личные журналы не зашифрованы. Модель рассчитана
на доверенную команду.

Проверки включают прежние сценарии журнала и несколько экземпляров приложения
с эмуляцией Диска: конкурентные изменения, конфликты, удаления, повторы, разрыв связи,
смена аккаунтов и офлайн-вход. Испытание с реальным пользовательским токеном в этой
сборке не проводилось. Подробности: `docs/SYNC-V14.md` и README.
