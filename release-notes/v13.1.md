Скачайте **Gradebook-v13.1.html** из Assets и откройте его в браузере. Всё приложение находится в одном файле: установка, сервер и дополнительные CSS/JS-файлы не требуются.

Изменения:

- Средний балл в строке каждого студента.
- Абсолютная и качественная успеваемость внизу журнала, в том числе при печати.
- Сортировка студентов по русскому алфавиту во всех списках.
- Кнопки «Предыдущий» и «Следующий» вверху профиля с номером позиции.
- Защита несохранённых правок при переключении студентов и сохранение возврата к исходному занятию.
- Исправлена инициализация календаря при загрузке приложения из отдельных файлов.

Средние баллы и статистика учитывают выбранный фильтр занятий. Учитываются числовые оценки от 2 до 5; пропуски, зачёты и баллы исключаются. Абсолютная успеваемость — доля студентов со средним баллом ≥ 3, качественная — ≥ 4. Студенты без числовых оценок не входят в знаменатель процентов.

**Переход с предыдущей версии:** откройте старый журнал, выполните «Настройки → Экспорт базы», затем в новой версии выберите «Настройки → Импорт базы» и загрузите JSON. Браузер может хранить данные разных локальных HTML-файлов отдельно. Также можно загрузить базу через настроенную синхронизацию с Яндекс Диском.

Архивы Source code предназначены для разработки. Для обычной работы нужен только **Gradebook-v13.1.html**.
