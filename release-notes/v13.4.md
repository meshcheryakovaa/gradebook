# редактирование оценок в таблице

Скачайте **Gradebook-v13.4.html** из Assets и откройте в браузере. Всё приложение находится в одном файле, установка и сервер не требуются.

Что изменилось:

- Оценки можно менять прямо в общей таблице журнала: дважды щёлкните по клетке, введите значение и нажмите Enter. Изменение сохраняется сразу, без кнопки «Сохранить».
- Enter сохраняет и переходит к следующему студенту ниже, Tab — к занятию справа, с Shift — в обратную сторону. Esc отменяет правку, щелчок в другом месте сохраняет её. Клетки занятий чужих подгрупп пропускаются.
- Комментарий к результату при правке не меняется. Средний балл и статистика успеваемости пересчитываются сразу.
- Мини-досье убрано: в карточке студента больше нет описания, тегов и блока среднего балла, а в «Настройки → Студенты → Изменить» снова обычное поле «Примечание». Записанные ранее примечания и теги остаются в базе.

**Обновление:** сначала экспортируйте базу из прежнего журнала через «Настройки → Экспорт базы», затем импортируйте JSON в новый HTML-файл. Можно также загрузить базу через настроенную синхронизацию с Яндекс Диском.
