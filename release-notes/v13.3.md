# «Н» в среднем балле

Скачайте **Gradebook-v13.3.html** из Assets и откройте в браузере. Всё приложение находится в одном файле, установка и сервер не требуются.

Что изменилось:

- Пропуск «Н» (в любом регистре) теперь учитывается в среднем балле как оценка 2. Это касается столбца «Средний балл» в журнале, абсолютной и качественной успеваемости и среднего балла в мини-досье студента.
- «Н/А», зачёты, текстовые обозначения и записи вида «5 баллов» по-прежнему не входят в средний балл.
- Студент, у которого есть только пропуски «Н», теперь получает средний балл 2,00 и учитывается в статистике успеваемости.
- Рамки оценок не изменились: у «Н» жёлтая, у «2» красная.

**Обновление:** сначала экспортируйте базу из прежнего журнала через «Настройки → Экспорт базы», затем импортируйте JSON в новый HTML-файл. Можно также загрузить базу через настроенную синхронизацию с Яндекс Диском.
